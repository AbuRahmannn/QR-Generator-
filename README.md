# QR Studio 🚀

A modern and customizable QR Code Generator built using Flask and JavaScript.
Generate beautiful QR codes instantly with custom colors, logo upload support, dark mode UI, and download options in PNG & SVG formats.

---

## ✨ Features

* 🔗 Generate QR codes from any URL
* 🎨 Customize QR color & background
* 🖼 Upload logo inside QR code
* 🌙 Dark mode support
* 📥 Download as PNG
* 📥 Download as SVG
* ⚡ Instant live preview
* 💻 Clean modern responsive UI

---

## 🛠 Tech Stack

* Backend: Python + Flask
* Frontend: HTML, CSS, JavaScript
* QR Generation: qrcode library
* Image Processing: Pillow

## 📦 Installation

Clone the repository:

```bash
git clone <your-repo-link>
cd qr-studio
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python qrscanner.py
```

Open in browser:

```bash
http://127.0.0.1:5000
```
