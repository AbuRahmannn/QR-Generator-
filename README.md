# 🚀 QR Studio Pro

A modern and beginner-friendly QR Code Generator built with **Python Flask**, **HTML**, **CSS**, and **JavaScript**.

QR Studio Pro allows users to generate QR codes instantly, customize colors, upload a logo, preview the result in real time, and download the QR code in PNG or SVG format.

---

## 📖 About the Project

QR Studio Pro is a web application that converts any website URL into a QR code.

Instead of typing long website links, users can simply scan the QR code with their smartphone and instantly access the website.

This project is perfect for:

* 🎓 Students learning Flask
* 💻 Beginners exploring Full-Stack Development
* 📁 Portfolio Projects
* 🏢 Businesses creating branded QR codes

---

## ✨ Features

* 🔗 Generate QR codes from any URL
* 🎨 Customize QR code and background colors
* 🖼 Upload a logo inside the QR code
* ⚡ Instant live preview
* 📥 Download QR codes as PNG
* 📥 Download QR codes as SVG
* 📱 Fully responsive design

## ⚙️ How It Works

### Step 1

Enter a website URL.

Example:

```text
https://github.com
```

### Step 2

Choose your preferred QR color and background color.

### Step 3

(Optional) Upload a logo to place at the center of the QR code.

### Step 4

Click **Generate QR Code**.

### Step 5

The application creates a QR code instantly and displays a live preview.

### Step 6

Download the QR code as PNG or SVG.

## 📦 Installation Guide

### 1. Clone the Repository

```bash
git clone https://github.com/AbuRahmannn/QR-Generator-
```

### 2. Navigate to the Project Folder

```bash
cd QR-Generator-
```

### 3. Install Required Packages

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

```text
http://127.0.0.1:5000
```
